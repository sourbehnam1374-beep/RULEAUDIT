# GAP score (Yilgor 2017) - archived run index

This path is retained for compatibility with the pre-v0.2.1 repository. The
earlier text snapshot used unseeded Sobol confidence estimates and legacy
mechanistic labels, so it is superseded.

The current seeded report, tables, and figures are versioned at
[`examples/gap/out/report.md`](../examples/gap/out/report.md). Reproduce them
with `python examples/gap/run.py`.

The worked GAP implementation is a software transcription used to demonstrate
the workflow; it is not an independently certified reference implementation.
All findings are conditional on the rule encoding, sampler, bounds, seed,
sample size, and software environment and do not establish predictive accuracy,
causality, clinical validity, or safety.
