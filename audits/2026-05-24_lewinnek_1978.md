# Lewinnek safe zone (1978) - archived run index

This path is retained for compatibility with the pre-v0.2.1 repository. The
earlier text snapshot used unseeded Sobol confidence estimates and legacy
mechanistic labels, so it is superseded.

The current seeded report, tables, and figures are versioned at
[`examples/lewinnek/out/report.md`](../examples/lewinnek/out/report.md).
Reproduce them with `python examples/lewinnek/run.py`.

The four-boundary violation representation is an author-created diagnostic
encoding of the published rectangle. Results are conditional on that encoding,
the sampler, bounds, seed, sample size, and software environment and do not
establish predictive accuracy, causality, clinical validity, or safety.
